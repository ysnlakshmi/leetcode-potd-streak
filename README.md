# LeetCode Daily Streak 🚀

This repository contains my daily **LeetCode Problem of the Day (POTD)** solutions.  
All solutions are synced automatically to GitHub to maintain an active streak and track progress.

## 📂 Structure
- Each folder corresponds to a problem.
- Inside each folder, you’ll find:
  - The solution file(s) (Python, C++, Java, etc.).
  - Optional metadata such as runtime and memory usage.
- Example:
  leetcode-potd-streak/
  ├── 1-two-sum/
  │   └── solution.cpp
  ├── 2-add-two-numbers/
  │   └── solution.cpp
  └── README.md (this file)

## 🎯 Goal
- Maintain a consistent daily streak on LeetCode.
- Showcase problem‑solving skills and coding practice.
- Keep solutions organized and accessible for future reference.
